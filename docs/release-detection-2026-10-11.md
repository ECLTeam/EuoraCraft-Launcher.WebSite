# 官网版本与更新日志检测

## 数据与范围

- 使用公开 GitHub Releases 列表获取版本号、发布日期、发布类型、版本页面和正文，包含预发布并排除草稿，按发布时间降序排列。
- 不使用只返回稳定发布的 `/releases/latest`。调研时最新版本为 `v0.1.0-beta.2+20260919`，两个公开版本正文均为空；没有日志时明确显示尚未提供。
- 首页下载区展示最新检测版本与日志入口；下载页支持版本选择、重新检测、对应版本更新日志与发布页面。
- GitHub Pages 为纯静态托管，检测在浏览器挂载后执行，构建不请求 API，不依赖服务端或浏览器中的访问令牌。

## 实现约束

- 页面间共享检测结果与进行中的请求，成功结果五分钟内复用；失败一分钟内不自动重复请求，手动检测可以重试。
- 网络或限流失败有明确提示，无发布和无日志有独立状态。刷新失败时保留已有信息并标记为上次结果，始终保留 GitHub Releases 下载入口。
- 远程 Markdown 使用 DOMPurify 清理后渲染，仅保留日志文本结构和链接；原有仓库自有 Markdown 组件保持不变。
- 平台说明以所选发布附件为准，不继续硬编码“最近版本”的支持列表。

参考：[GitHub Releases API](https://docs.github.com/en/rest/releases/releases#list-releases)、[DOMPurify](https://github.com/cure53/DOMPurify)。

## 验证

- 实网浏览器检测成功：`v0.1.0-beta.2+20260919`，预发布，发布日期 2026-09-19；GitHub 正文为空，页面明确提示未提供更新日志。首页与下载页展示一致。
- 34 项浏览器检查通过：版本排序与草稿过滤、历史版本与下载链接联动、Markdown 标题/格式/表格、危险 HTML 与链接清理、空日志与空发布、刷新与失败重试、失败保留上次数据，以及页面间进行中请求与五分钟缓存复用。共享请求检查仅发出一次请求，无应用错误或水合警告。
- 中文与英文在 320、390、768、1600 像素宽度下无横向溢出。
- 语言菜单使用 `bodyLock: false` 保留页面滚动条。修复前桌面悬浮栏向右移动 5 像素，修复后首页/下载页、两种语言、四种宽度下位置与宽度一致；51 项语言菜单检查通过，包含键盘选择与 Esc 关闭后恢复焦点。
- `pnpm lint` 与 `pnpm typecheck` 通过；lint 仅保留原有 `MdContent.vue` 的 `v-html` 警告。
- `pnpm build` 静态生成成功（69 个页面/资源路由），六个主页面与日志锚点完整，生成 HTML 没有测试版本数据。
- 验证脚本、日志与实网截图保存在忽略的 `output/playwright/release-detection/`。
