# 导航与首屏调整

用户已选定直接介绍产品的表达方式，并授权实施。

## 选定方案

- 主标题保留 EuoraCraft Launcher。中文介绍采用“开源 Minecraft 启动器，支持多实例管理、模组与资源安装、联机及插件扩展。”；同步英文。
- 保留原有悬浮页头、12px 顶部间距、圆角及玻璃质感，使品牌与正文左对齐。以文字导航和当前页短下划线建立层级，下载保留主按钮。
- 语言选择保留现有单选语义、键盘操作和持久化，调整为右对齐的紧凑面板。取消蓝色选中背景，保留勾选、悬停与键盘焦点反馈。桌面选项 36px，窄屏 44px。
- 首屏移除装饰徽章、星形图注和泛化宣传尾句；在线体验使用轻量入口，背景 Aurora 降低至原强度的 35%。
- 保留所有路由、真实界面图片、亮暗主题和移动导航。
- 后续调整：首页首屏占满可视高度，扣除悬浮页头在文档中的高度与顶部间距，移除原有 760px 高度上限。首屏底部添加向下浏览入口，滚动至功能介绍并转移焦点；减弱动效时直接定位。内容较高的窄屏允许首屏自然增高，避免裁切与按钮重叠。

## 验证

- `pnpm lint`、`pnpm typecheck`、`pnpm build` 通过。保留既有 MdContent 的 `v-html` 警告以及构建依赖告警。一次构建遇到 Windows 资源不足，关闭验证浏览器并仅对该次构建设置 `RAYON_NUM_THREADS=2` 后通过；未更改项目构建配置。
- Edge 验证最终静态产物：322 项检查通过，覆盖中英文、亮暗主题以及 320 / 390 / 768 / 1024 / 1280 / 1600px。无横向溢出，桌面导航分组不重叠，品牌与正文对齐。
- 菜单右对齐、6px 间距、36 / 44px 选项高度、唯一勾选标记和不透明亮暗面板均通过。键盘 Enter 打开、End 导航、Space 确认、Escape 关闭与焦点恢复，以及语言刷新保存通过。
- 移动菜单打开、Escape 关闭、跳转后关闭、六条路由和独立在线体验 iframe 均通过。首页保持静态截图，悬浮页头滚动后仍距离顶部 12px。验证期间无浏览器错误或 hydration 警告。
- 附带观察：当前选择组件使用 Enter 确认后语言会更新，但菜单仍可能展开；Space 确认正常关闭。本轮保留现有组件事件逻辑，未加入键盘事件绕行补丁。
- 截图、脚本和日志位于被 git 忽略的 `output/playwright/nav-refresh/`。原有修改文件中，除本轮明确调整的五个文件，其余 47 个文件内容哈希保持不变。未提交或推送。
