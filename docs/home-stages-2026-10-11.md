# 首页分阶段浏览

用户希望只有展示内容按阶段切换，开源区、下载和页脚在展示区外正常滚动。过渡时同时展示相邻两屏，然后自动对齐目标位置；页面滚动条实时反映实际位置。顶部栏仅浮在内容上方，不保留布局占位。

## 实施方案

- 展示保留五个阶段：首屏、实例、资源、联机、插件，每屏为 `100dvh`。开源区和下载区按普通内容排在展示之后，接普通页脚。
- 统一使用文档滚动和可见的原生页面滚动条，取消独立展示滚动容器及其隐藏滚动条。滚轮与键盘定位相邻阶段，拖动滚动条或触屏滚动后在展示范围内对齐最近阶段；开源、下载和页脚不吸附。
- 顶部栏使用固定叠层，页头不占据文档高度。首屏从页面顶部开始，背景与内容过渡到栏的下方；小屏阅读区域有内部安全边距，防止标题被遮挡。底部控制也固定叠在展示之上，离开展示后隐藏。
- 普通模式使用平滑滑动过渡，两屏在展示区内同时出现后对齐目标位置。滚动结束时再更新阶段计数和焦点；动画期间不接受连续翻页。减弱动效模式直接定位。
- 每阶段有自己的内容阅读区域，小屏或大字号下可在该阶段内阅读完整内容。
- 收尾区采用紧凑排版：开源区保留项目说明、源码／反馈／文档入口及三项信息；下载区移除大玻璃卡片，桌面左侧标题与说明、右侧操作，窄屏上下排列。标题最大 30px，GitHub 为轻量操作，按钮保留 44px 触控高度。
- 保留已调整的具体功能文案；其他路由保留正常滚动，检查固定顶部栏不会覆盖标题。
- 动画结束与焦点更新参考：[CSSOM View 的 scrollend 事件](https://drafts.csswg.org/cssom-view/#eventdef-document-scrollend)。

## 展示滚动验证（前一轮）

- Edge 134 项检查通过。动画采集 29 个滚动位置，`window.scrollY` 与原生文档滚动条位置逐帧一致，顶部栏始终距顶部 12px；过渡仍同时显示相邻两屏。
- 首屏顶边为 0，没有页头占位。六阶段各占完整视口；中英文、1600×900 / 1280×720 / 390×844 / 320×568 的上下浏览、长内容、键盘、暗色模式和减弱动效均通过，没有横向溢出。
- 两屏之间的滚动位置能自动对齐。下载在展示之外，可普通滚动访问，展示控制离开后隐藏。其他五条路由的标题均未被悬浮栏遮挡，页脚各一个。
- 实际用鼠标拖动原生滚动条至 583px，松开后自动对齐到 900px。可见滚动条截图验证时关闭了 Playwright 默认的隐藏滚动条参数，仅影响验证浏览器。
- 验证期间没有浏览器错误或 hydration 告警。`pnpm lint`、`pnpm typecheck`、`pnpm build` 与 `git diff --check` 通过，保留原有 MdContent 的 `v-html` 告警。静态产物确认六屏展示、独立普通下载区、一个页脚和 `euora.cn` 配置。
- 本轮仅修改七个相关文件，另外 50 个既有文件内容哈希保持不变。未提交或推送。
- 实际切换录屏为 `output/playwright/scroll-layout/scroll-demo.webm`，包含可见的原生页面滚动条、两次向下及一次向上过渡。
